# Anti-Defensive Writing

A Codex skill for making academic and technical prose direct, concise, and evidence-calibrated while preserving necessary methodological, ethical, legal, and safety limits.

## Use

Invoke it explicitly with:

```text
$anti-defensive-writing Revise this passage for direct, evidence-calibrated prose. Preserve the facts, claims, and necessary limitations.
```

Codex can also select it automatically for relevant writing and editing tasks.

## Install

- User-wide: place this repository at `$CODEX_HOME/skills/anti-defensive-writing/`.
- Repository-wide: place it at `.agents/skills/anti-defensive-writing/`.

The skill specification is in the repository-root `SKILL.md`.
